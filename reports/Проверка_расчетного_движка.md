# Проверка браузерного расчётного движка

Дата: 22 октября 2026 года.

Расчёты выполняет ngspice 46, собранный в WebAssembly (пакет @o.z/ngspice-wasm 0.0.0). Для работы опубликованного сайта не нужны установленная TINA, Python, локальный ngspice или сервер расчётов. Сам код WebAssembly входит в собранный файл worker. Загрузка сайта с хостинга необходима.

Проверены:

- Рабочая точка схемы BF240: результат совпал с настольным ngspice 47.
- Выходная характеристика: 500 точек от 0 до 40 В.
- Семейство при IБ = 10, 40 и 100 мкА: по 500 точек на кривую.
- Частотный анализ RC-цепи: 91 точка, комплексные значения; совпал с настольным ngspice 47. Модуль передачи около частоты среза 159 Гц равен 0,708587.
- Переходный процесс RC-цепи с синусоидой: 3008 точек; совпал с настольным ngspice 47.
- Связь интерфейса с настоящим модулем расчёта через отдельный worker проверена в Node Worker Threads. Проверена отмена до начала и во время расчёта.
- Отдельная производственная сборка Vite успешно сформировала браузерный worker со встроенным WebAssembly.

Наибольшее относительное расхождение с ngspice 47 в проверенных DC-точках — 0,0004723 %. Для сравнения использованы одинаковые настройки reltol=1e-6, abstol=1e-12, vntol=1e-8. Полные данные сравнения находятся в solver-numerical-verification.json.

h-параметры BF240 при UКЭ = 16 В и IБ = 40 мкА рассчитаны центральными разностями, ΔIБ = 1 мкА, ΔUКЭ = 0,1 В:

- IК = 4,436642 мА; UБЭ = 0,681348 В.
- h11 = 793,199 Ом.
- h12 = 0,0000191516.
- h21 = 113,8615.
- h22 = 0,0000627897 См.
- Rвх = h11; Rвых = 1/h22; β = h21.

Исходные девять точек, обозначения векторов и формулы сохранены в h-parameters-worker.json. Это результат модели, а не измерение реального транзистора.

Ограничения: расчётный движок самостоятельный и не тождественен внутреннему решателю TINA. Сравнение с установленной TINA пока не выполнено. Проверка Node Worker и сборки Vite не заменяет отдельную проверку интерфейса в настоящем браузере.
