# Локальные рисунки TINA

Исходные изображения берутся только из собственной установленной TINA-TI 9.
Они находятся в игнорируемой папке data/tina и не публикуются в Git-зеркале.
Vite обслуживает data как каталог статических ресурсов.

Миниатюры:

    python tools/extract_assets.py "путь к установленной Tina 9 - TI"
    python tools/extract_assets.py --check

Схемные формы: fixture reports/symbol-oracle.TSC экспортирован оригинальной
TINA через Файл → Экспорт → Метафайл Windows. Общий декодер:

    python tools/extract_symbol_vectors.py reports/symbol-oracle.wmf data/tina/component-symbols.json

Для вариантов VG дополнительно экспортированы общие fixtures sine/rectangle;
их SVG-примитивы сохраняются в ключах VG_sine/VG_rectangle того же файла.
Неподдержанные WMF-команды вызывают ошибку, а не тихий пропуск геометрии.
Начальный масштаб/смещение декодера относятся к указанному общему fixture,
скрипт не является универсальным импортом произвольных WMF.

При синхронизации не копировать data/** и dist/tina/**. Сохранение схем
пользователя остаётся TSC; JSON здесь — внутренние графические ресурсы.
