## Исправленная интерпретация сопротивления

Предыдущее предположение о float64 по p+34 было неверным. Проба VG_resistance50_probe.TSC по этому смещению показала в native свойствах 1,811784E-307 Ом, а не 50. Проба VG_resistance50_aligned_probe.TSC с float64 по **p+35** показала ровно 50 Ом. Байт p+34 остаётся отдельным непрозрачным нулевым полем; ненулевой вариант сейчас отклоняется.

Native PSpice-экспорт обеих проб не содержит последовательного резистора. Поэтому экспорт нельзя считать достаточным эталоном сопротивления. В оригинале выполнен переходный процесс для согласованной 50-омной пробы и сохранён VG_resistance50_native_transient.txt: 301 точка идеального возбуждения Vin и 201 точка Vout. Возбуждение совпало с нулевой пробой; Vout отличается до 50,11548 мВ.

Вывод, проверенный расчётом: последовательный резистор 50 Ом воспроизводит этот RC-сценарий с максимальным расхождением Vout 10,14985 мВ. Модель без сопротивления даёт 58,40552 мВ. Независимое аналитическое решение RC с tau=(1000+50)*1мкФ совпадает с браузером <10 мкВ на всей сетке. Это подтверждает конкретный сценарий; общий набор типов источников и все режимы оригинала не проверены.

## Реализация и проверки

- Сайт редактирует sine/square, амплитуду, частоту, фазу или фронт, DC и внутреннее сопротивление; записываются только подтверждённые слоты. Остальные байты записи сохраняются.
- exportSpice включает последовательное сопротивление в общую схему, поэтому оно учитывается в OP/DC/AC/transient. Численная сверка с оригиналом пока выполнена для RC transient; остальные анализы требуют собственных native эталонов.
- Для ненулевого сопротивления график напряжения внешнего узла отличается от идеального возбуждения. Служебный внутренний узел доступен в выборе кривых.
- Исправлена Buffer.slice/DataView ошибка: запись могла попасть в неправильное место общего backing buffer. Используется независимая Uint8Array и явные byteOffset/byteLength.
- Исправлен повтор после ошибочного ввода: rollback сохраняет объект документа, которым пользуется открытый диалог. Иначе второй submit менял устаревший документ. При ошибке также сохраняется предыдущая redo-ветка.
- Browser undo вернул 2 В/200 Гц/30°, redo восстановил 0,75 В/500 Гц/45°. Square с R=50 рассчитан в браузере: 25101 точка. Экспорт результата проверен: R_vg_series_8 vg_internal_8 1 50 присутствует.
- npm test: проходят все 12 групп, включая новый native-generator-write (Buffer/subarray, неизвестные байты, round trip, атомарные отказы, сопротивление, коллизия служебного имени). Опциональный Python oracle явно пропущен из-за отсутствующих независимых файлов. npm run build проходит; два прежних предупреждения сборщика остаются.

DeepSeek реально вызван через разрешённый OpenRouter: generator-write-tests $0.0034779, resistance-review $0.0072066. Ответы проверялись: исправлены выдуманные поля data_offset и Component.c в предложенных тестах; не приняты неверные выводы review о бесконечном периоде и коллизии разных record index. Длина проверки согласована до p+43. Ключ читается только из окружения.

Промежуточные VG_native_resistance50.TSC/_enter.TSC не изменили сопротивление при попытке программного ввода и не являются 50-омными эталонами. VG_browser_ui_verified.cir — сохранённое воспроизведение ошибки до исправления retry, не успешная проверка новых параметров. Не использовать их как положительные эталоны.

## Начат следующий этап: native scope

На чистом RC_native_sine.TSC открыт scope236. Run запускает обновление, Stop останавливает сбор; после Stop переключение входа оставляет прежний кадр до следующего Run. Комбобоксы реально содержат Mode: Single/Normal/Auto, Source: Ext.-Func.Gen./Vout, Channel: Vout/пусто; X Source: Vout. Это два наблюдаемых списка, не доказательство наличия второго VM в данной схеме.

Снимки native-scope-sine-run.png: DC, сигнал с центром выше нуля (DC1В); native-scope-sine-ac-settled.png: после установления AC центр около нулевой линии; native-scope-ground-running.png: GND при Run даёт нулевую линию. Снимок сразу после AC ещё содержал предыдущее смещение/переходный процесс: нельзя заменять AC простым вычитанием среднего без измерения динамики. Точная постоянная времени и взаимодействие coupling/trigger неизвестны; перенос AC пока не сделан. Scope остановлен после наблюдений, оригинал оставлен открытым.
