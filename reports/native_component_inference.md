# Исследование четырёх базовых элементов TINA 9–TI

Исследованы локальные файлы данных: 1482 примера `.TSC` и каталог `clcf.cat`. Исполняемые файлы не декомпилировались. Поля прочитаны непосредственно из файлов; визуальная и численная проверка в оригинальной TINA не выполнялась.

Полные пути доноров, номера записей, исходные Base64-записи, смещения и параметры сохранены в `native_component_inference.json`. Пути в JSON отсчитываются от `work/tina/DesignSoft/Tina 9 - TI`.

| Элемент | Тип записи | Количество v66 | Байты общего блока после строки корпуса | Координаты выводов до поворота |
|---|---|---:|---:|---|
| Переключатель SPST | 0x235 | 2 | 54 | (0,0), (40,0) |
| Диод | 0x218 | 14 | 54 | (0,0), (40,0) |
| Однополюсный пробник напряжения | 0x205 | 1139 | 53 | (0,0) |
| Идеальный ОУ | 0x257 | 2 | 53 | (−32,−16), (−32,16), (32,0) |

Координаты выводов получены сопоставлением концов проводов с положением и поворотом элемента. Полярность входов ОУ и анод/катод диода таким способом не устанавливаются.

Переключатель SPST:

- Донор состояния 0: `EXAMPLES/NSC Test Circuits/LMV710 Test Circuit.TSC`, запись 22, SW-SPST1, (184,240), поворот 0. Смещение параметров 133; размер записи 155 байт.
- Донор состояния 1: `EXAMPLES/WAV file examples/Distortion.TSC`, запись 46, SW-SPST1, (344,200), поворот 3. Смещение параметров 133; размер 155 байт.
- В обоих донорах блок параметров имеет 22 байта: `u16` состояния по смещению +0; `f64` 1e9 по +2; `f64` 0 по +10; `u32` 0 по +18.
- Значения 1e9 и 0 похожи на сопротивления разомкнутого и замкнутого переключателя. Соответствие состояния 0/1 положению «разомкнут/замкнут» пока не доказано. Его нельзя выдавать за подтверждённую совместимость.

Диод:

- Простой донор: `EXAMPLES/TI Test Circuits/TLC555_ASTABLE.TSC`, D1, модель 1N4148. После общего блока идут строки с длиной: имя модели, семейство `Standard`, затем однобайтовый признак встроенной модели.
- При признаке 0 численная модель в `.TSC` отсутствует: её нужно разрешать через каталог.
- При признаке 1 далее идут `u32` числа строк; каждая строка содержит строку CP1251 с длиной и `u32` дополнительных флагов. После строк следует строка группы `[All]`, далее непрозрачный хвост свойств.
- Проверенные доноры встроенного SPICE-текста: `EXAMPLES/Smps/TPS40210/TPS40210_AVG.TSC`, D1, MBRS340T3; `EXAMPLES/Smps/LM5116/LM5116_TRANS.TSC`, D1/D2, CMPD2003. Обе двухстрочные `.MODEL … D (…)` успешно извлечены с сохранением всех границ.
- Каталог: дескриптор Standard по адресу 0x2260B6 содержит 19 параметров. Запись модели — 26 байт описания и 19 чисел `f64`, всего 178 байт. Для 1N4148 адрес записи 0x4F971D; для 1N1183 — 0x4F7937. Точные значения приведены в JSON.
- Имеется нестандартный параметр RZ. Порядок/смысл двух шумовых параметров AF/KF требует проверки: подписи дескриптора дают AF=0, KF=1, что отличается от обычных значений SPICE. Полную численную эквивалентность простой подстановкой параметров утверждать нельзя.

Пробник напряжения:

- Донор: `EXAMPLES/Filters_Others/10MHz LPF SK.TSC`, Vout.
- После 53 байт общего блока идут два непрозрачных байта. Найдены сочетания 00 01 (901 экземпляр), 01 01 (160), 00 02 (75), 00 00 (3). Их назначение не установлено; при записи нужно сохранять.
- Для самостоятельного решателя идеальный однополюсный пробник измеряет потенциал своего узла относительно земли без нагрузки. Это обоснованная независимая реализация, но не расшифровка флагов TINA.

Идеальный ОУ:

- Доноры: `EXAMPLES/WAV file examples/Distortion.TSC`, запись 43; `EXAMPLES/WAV file examples/Bass Treble Tone Control.TSC`, запись 44. Оба IOP1, поворот 0, три вывода, размер 102 байта.
- Общий блок имеет 53 байта, и после него запись заканчивается. Сохранённых параметров усиления, полосы и ограничения напряжения нет.
- Выход (32,0) и входы (−32,±16) согласуются с проводами обоих примеров. Какой вход инвертирующий и является ли внутренний решатель строго идеальным, по этим записям не доказано.

Найдены также версии записей 51, 53, 54, 55 и 57. Их заголовки и размеры общих блоков различаются. Нельзя применять к ним разбор версии 66 только потому, что тип элемента совпадает. В отчёте старые версии учитываются статистически, но не объявлены поддержанными.
