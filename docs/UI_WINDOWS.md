# Приёмка окон TINA

Общий статус переноса ведётся в [STATUS.md](STATUS.md). Этот файл задаёт правила отметок **рядом с реализацией окна**, чтобы неполную форму нельзя было принять за законченный перенос.

## Отметки в исходниках

Искать `TINA-UI: window=`. У отметки есть постоянный идентификатор окна, `status`, число подтверждённых **полных сверок** (`full-parity-checks`) и конкретные пробелы. Ноль полных сверок не означает, что код никогда не запускали: это означает, что его полная приёмка относительно оригинала не подтверждена. Исторические частные проверки не пересчитывать в выдуманное число успешных проверок окна.

- `partial` — перенос неполный или полная сверка не проведена.
- `verified` — состав, поведение, состояния и сохранение проверены целиком в указанной области; рядом обязателен путь к свидетельствам и дата.
- Для дополнительного окна сайта указывать, что у него нет аналога в TINA, и проверять собственный описанный сценарий.

Сборку и численные тесты учитывать отдельно от проверок интерфейса. Просмотр исходного снимка TINA не считается пройденной проверкой сайта. Проценты сходства не использовать.

## Окна и точки входа

| Окно | Код | Текущее ограничение |
|---|---|---|
| Каталог моделей | `src/catalog-dialog.ts` | Частичный каталог; локальная и публичная библиотеки различаются. |
| Свойства компонента и параметры моделей/генераторов | `src/properties-dialog.ts` | Общие профили семейств, полной приёмки всех составов нет. |
| Объект управления; DC; AC; переходный процесс | `src/native-analysis-dialogs.ts` | Отдельные рабочие сценарии; полный состав и сохранение всех режимов не приняты. |
| Постпроцессинг | `src/postprocess-dialog.ts` | Перенос структуры оригинала; неподдержанные функции должны быть видимыми и неактивными. |
| Настройка оси | `src/plot-settings.ts` | Полная сверка оформления, полей и сохранения не принята. |
| Текст | `src/text-dialog.ts` | Не все свойства оформления перенесены. |
| Осциллограф | `src/scope-dialog.ts` | Частичный прибор, полной приёмки режимов нет. |
| Автоподбор BJT | `src/bjt-auto-dialog.ts` | Дополнительная функция сайта. |
| Сохранить как, вспомогательные формы, таблица, h-помощник | `src/main.ts` | Частные реализации; не считать копиями оригинальных окон без сверки. |

## Обязательная проверка перед статусом verified

1. Сопоставить с реальным окном TINA названия, порядок, группы и все управляющие элементы. Неподдержанные возможности остаются на месте и отключены; без фиктивных активных кнопок.
2. Проверить первое открытие на чистом состоянии: пустые поля и значения по умолчанию соответствуют оригиналу, нет чисел из чужого варианта.
3. Проверить выбор, изменение, подтверждение, отмену, повторное открытие, закрытие и раскрываемые части. Отмена не применяет изменения; раскрытие не теряет введённые данные.
4. Проверить общий стиль, отсутствие обрезания текста и элементов, работу клавиатуры и минимальный поддерживаемый размер окна.
5. Пройти реальный сценарий с результатом, включая TSC/график там, где окно их меняет. Сохранить снимки и короткий протокол с точным объёмом проверки.

До выполнения этих пунктов окно остаётся `partial`. Нельзя уменьшать состав формы и объявлять её законченной только потому, что один расчёт выполнился.
