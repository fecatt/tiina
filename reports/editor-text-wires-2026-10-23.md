## Что изменено

- Обычное движение компонента сохраняет ортогональные участки, возврат убирает лишние изгибы. Импортированные диагонали не нормализуются.
- Вставить -> Прямой провод — расширение браузера: намеренные диагонали, действующая native запись.
- Кнопка T, Вставить -> Текст, Ctrl+T. Многострочный CP1251, размер1..72пт, свойства двойным щелчком, движение/копирование/удаление/undo/redo, сохранение native TSC; fit и SVG учитывают текст. Отображение простого текста; native рамки, rich formatting, формулы, bold/italic и смена font пока не реализованы.
- Меню по runtime inventory, флажки с aria-checked; отсутствующие команды серые с пометкой «будет добавлено». Добавлены T&M/TI Utilities. Реальные View toggles: grid/pins/values/elements/labels/panels; масштаб через submenu. Это не полное воспроизведение семантики всех пунктов. Не все показанные native shortcuts подключены.
- Выбор цепочки проводов через degree-two endpoints одним щелчком без слияния/перезаписи opaque native записей. Реальные разветвления, выводы компонентов и различие style останавливают цепочку. Ctrl/Shift оставляют ручной выбор.
- translateSelection учитывает электрические соединения только по концам. Интерьер изгиба больше не порождает phantom bridge. Браузерный UI: два участка выбраны вместе и смещены вверх40, число записей не выросло. Это исправление browser editor; native алгоритм произвольного wire dragging ещё требует отдельного сценария.
